# Licence and citation

## Licence

The repository is a fork of ns-3.47. Its [`LICENSE`](https://github.com/YKushal-hub/ca-tbl-localization/blob/main/LICENSE) states that the contributions are mostly licensed as
**GPL-2.0-only**, with some code licensed differently; the [`LICENSES`](https://github.com/YKushal-hub/ca-tbl-localization/blob/main/LICENSES) directory holds the set present
(BSD-2-Clause, BSD-3-Clause, GPL-2.0-only, GPL-2.0-or-later, NCSA). The common denominator, and the requirement for
contribution, is compatibility with GPLv2-only.
