## 4. Rules this session learned (apply them locally)

1. **Never commit to the checkout a campaign runs from.**
   - **What happens:** the simulator writes `source <HEAD>` into every `run_id.txt` at launch, so a commit
     mid-campaign splits the sources and fails the registered one-source check. TDOA-TIMING-B's first run was lost
     this way, and so was ORACLE-ESC's first launch.
   - **Fix:** run from a detached worktree. Copy `build/scratch/ns3.47-ca_tbl_causal_sim-optimized` and
     `build/lib` into its `build/`, because a symlink shows as untracked.

     ```bash
     git worktree add --detach ../ca-tbl-frozen HEAD
     mkdir -p ../ca-tbl-frozen/build/scratch
     cp build/scratch/ns3.47-ca_tbl_causal_sim-optimized ../ca-tbl-frozen/build/scratch/
     cp -r build/lib ../ca-tbl-frozen/build/lib
     cd ../ca-tbl-frozen && bash scripts/<name>_run.sh <outdir>
     ```
2. **`.gitignore` keeps only `arm_summary.csv`, `run_id.txt` and `.md` under `results/`.**
   - Anything else a RESULT section cites must be added with `git add -f`. Check with `git ls-files results/<dir>`.
   - **Consequence (fact):** `scripts/paper_tables.py` (Tables 1–4) cannot regenerate from git alone. It needs
     `rc` and `subject_summary.csv` for camp_final, lora_cmp, lora_cmp2 and fixes_n26, which were never tracked; on
     this checkout it stops with `AssertionError: ('A', 'CA-TBL + N.26 fixes', 0)`. Regenerate where those full
     results directories exist.
3. **Disk.** One 1800 s multi-arm cell writes 20–100 MB before pruning. The cloud session could not hold a campaign
   unpruned.
   - `results/*/prune_cells.py` verifies every file against the cell's `run_id.txt` digest, then deletes the files
     the analysis does not read.
   - Locally, with enough disk, skip pruning and keep the traces.
4. **Stopping a runner.** `pkill -f <pattern>` can match the shell that runs it. Kill by PID, and check that only
   one `*_run.sh` parent remains (`ps -eo pid,ppid,args`).
5. **Dominance in registered rules.** In any rule that compares a new setting against a family of settings, compare
   only against the family's non-dominated members (ORACLE-ESC's flaw).
6. **Repository rules.** `docs/THESIS_TASKS.md`: no thesis prose in this repository. `nohw_section.md` is a paper
   section draft for the owner to place; it is not thesis text.
