# NOT DONE — the register of what this session did not do

**Written** 2026-09-05 at the close of the session, deliberately, so that what was left
undone is on the record rather than implied by its absence. Each entry says *why* it was
not done, because "we ran out of time" and "this is not buildable" are different
statements and only one of them is a limitation.

---

## 1. Not done because it would have been unsafe to start

**C2 — two tags in the scenario.** The refactor is a day; proving `--nTags=1` leaves the
draw order byte-identical against the shared `macRng` stream is the unbounded part.
`docs/WORK_PACKAGES.md` says starting it and not finishing "leaves the tree in a state
where no result is comparable", and a half-finished C2 would have invalidated every
comparison landed this session. **Not started on purpose.**

**C3 `QUERY`/`RESPONSE`, C4 multi-target arbitration.** Both gated on C2 — C3 needs a
second target to scope between, C4 needs one to arbitrate between. Blocked by the item
above, not by effort.

---

## 2. Not done because a prerequisite is missing

**C5 — hop-provenance.** Gated on writing the relayed-ranging error model — how range
uncertainty composes across a hop — and having it reviewed *before any code*. That model
does not exist. Until it does, C5 is not buildable, and `hopWeight` stays at 0: a non-zero
weight on a hop count that is structurally always zero changes nothing, and applied to an
admitted-but-unreachable peer it degrades the score for an **energy** defect rather than a
provenance one — a wrong result that looks like a working mechanism.

**A4 — tier-1 measurement calibration.** The work package says to compare reported sigma
against realised error "from the existing traces". **Those traces do not exist** — the
repository tracks summaries and sidecars, and every `trace_*.csv` regenerates from seed.
A4 therefore needs a density-sweep regeneration that nobody has costed. This was found
during the session and is not in any plan.

**A5 — complementary siting.** Gated on A4 by an explicit ordering rule: A5 must not
answer a question a calibration fix already answered.

---

## 3. Not done because it is closed

**A8 — a further PCS functional form.** Three forms have now failed the same
monotone-of-filter-statistic control: `legacy`, `v2`, and both repairs measured this
session. `PREREG_PCS_FORMS.md` §6 and `docs/WORK_PACKAGES.md` A8 both say the same thing
about that outcome. **Do not run a fourth.**

---

## 4. Not done because it is not a simulation problem

**The §4.1 / §4.2 provenance gap.** Both sections are now withdrawn. Restoring them needs
either a decision to restate the claims without the unrecoverable numbers, or a fresh
campaign that records its own invocation. No amount of compute recovers a flag set that
was never written to disk.

**A gate that asserts cited directories exist.** The absence of `results/p10_grid` passed
every gate in the project. A check for it has to read the citations and test for absence —
it cannot be a scan of what is present. Specified here, not built.

---

## 5. Not done, and small

**A3 — intra-cycle handshake deferral.** Small–moderate code, derived but never run. It
would convert the duty-cycle finding from a constraint into a mitigation, which is one of
the two mechanism results that survive independently of the decision layer. **This is the
best next item.**

**A6 sweep.** The flags exist and are null-controlled; the sweep grid is specified nowhere
and was never chosen. CAL-03/CAL-04 remain unmeasured — now for want of a decision about
the grid, not for want of a flag.

**G11.** Red, and left red. The analytic propagation model does not reconcile with the
engines — r80 off by 19.6/38.7/94.9 % against a 15 % criterion. The module's own docstring
says refusing to reconcile is its purpose, and the gate prints *"Do NOT tune the analytic
model to match."* Closing it means deciding which side is wrong, which is research.
