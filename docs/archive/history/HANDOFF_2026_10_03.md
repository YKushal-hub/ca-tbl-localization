## 3. Owner decisions pending

1. **SY-2, the LR1121 radio basis.** It needs the datasheet's current tables: install
   poppler-utils so the PDF can be read, or paste the tables.
2. **N.14, floor-first fix selection.**

     GEO-01 cell.

## 5. Rules this programme re-earned

- **`run_id.txt` reads `git rev-parse` and `git status -- src scratch` at run time.** So
  never commit or edit `src/` or `scratch/` while a registered campaign runs.
- **The simulation is deterministic.** A cell re-run reproduces every file byte for byte,
  which is what makes resuming an interrupted grid legitimate (GEO-01's `RUN.md`).
- **Run long campaigns detached** (`setsid nohup`). A background tool call dies with its
  session, or at its 2 h limit.
- **A registered document is not edited after the fact.** G10's citation audit takes an
  enumerated allowance instead (`13ddfc6`).
- **A gate that fails by finding stays failing,** listed and explained (G24), never passed
  by absence.
