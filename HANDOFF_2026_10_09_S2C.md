## Known provenance flaw, found at the end of this session

Every campaign run log written with the pattern `echo "$(date ...) (all cells done, runner exit $?)"`
records `date`'s status, not the runner's, so its "runner exit 0" is not evidence. This affects
this session's S2-C, S2-C-NLOS and S2-C-ACQ logs (their `RUN.md` files now say so), and the same
pattern in the TOF-FIELD, ACC-A, ACC-B, ACC-B2 and ACC-A-OPPOINT `RUN.md` files, which are not
edited here (dated evidence). In every case the per-run `rc` files are the evidence, and each
registered analysis checks them. The same masking hid this suite's exit code: its log ends
"SUITE FAILED", as expected for the known reds.

- **The `run_id.txt` `source` line is the run directory's git HEAD, not the build commit.** Pin a

  `build <date>` compile stamp.

### R1. Fix the unknown-start acquisition lock-in (TECH_DEBT N.54) — highest value

- **What is known.** Under `--unknownStart` at 5 km every arm stays around 0.2 within 25 m, with a
  median error of about 300 m. `--acquireMinAnchors=3` did not help (S2-C-ACQ). So the lock-in is
  not only the two-range solves.
- **Hypothesis.** The EKF's range updates are linearised at a box-centre prior kilometres off.
- **Proposed flag** (default off, e.g. `--acquireReinit`). On the first cycle with at least three
  ranges and the filter not yet acquired:
  - solve `RawMultilaterationWeighted` (`src/lora-physics-engine/model/ca-tbl-policy.cc:816`)
    from several starting points (box centre plus the anchors' centroid);
  - keep the solution with the smallest residual;
  - re-initialise the EKF there (`m_ekf.Init`) with the fix's covariance, instead of a range
    update.
- **Entry points:**
  - `acqBlock` at `ca-tbl-policy.cc:1257`;
  - the coast branch just below it;
  - `m_acquired = true` at `:1383`;
  - `CaTblPolicy::Initialize` near `:705`.
- **Test.** Register against S2-C's U_A and U_B cells (the same flags as `PREREG_S2C`, arms
  `ca_tbl_full,fixed_threshold,static_2p4`, `--fixedVarThreshold=12`, seeds 1-20). First run a
  2-seed byte-identity stage with the flag off against U_A, as S2-C-ACQ did.
- **Metrics:** w25, w25acq, first fix, never-fix, median error, recovery
  (`scripts/s2c_analyse.py` functions).
