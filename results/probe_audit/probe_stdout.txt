How to act on this:
  1. Monotonicity must be OK on all three tiers. If not, nothing below
     is measuring distance -- fix that first.
  2. Size the anchor triads from the measured r80 values, not from
     datasheet range figures. --uwbTriad <= uwb r80, --t2Triad <= 2p4 r80.
  3. Tier 1 needs r80 to cover the gateway spacing that BuildDeployment()
     uses (0.9 * boxHalf, so ~1900 m diagonal at the default 3 km box).
     If 868 r80 is well below that, reduce --boxHalf rather than pretend
     the link closes.
  4. Ranging error is reported alongside PDR for a reason. A tier whose
     mean range error is a large fraction of the true distance is not
     contributing ranging information even when its PDR is 1.0 -- its
     fixes come from multilateration geometry, not from link ranging.
     Read the 868 column with that in mind before reading any RMSE.
