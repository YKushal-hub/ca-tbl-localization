## Step 5 — exploratory tuning sweep for `--imuQuScale` (≈ 15 min; only after Step 4)

The cloud's registered ACC-A campaign fixed k = 10 a priori, and S2's plan wanted a tuning sweep
on held-out seeds, which the cloud skipped for time. Run it here on seeds 21–30, which ACC-A
never evaluates. Label it **exploratory, tuning seeds, this machine only**. It is not paired with
any cloud cell.

```bash
OUT=$(mktemp -d /tmp/lv_ksweep.XXXX); BIN=$PWD/build/scratch/ns3.47-ca_tbl_causal_sim-optimized
P="--specProfile=true --duration=1800 --trace=true --arms=ca_tbl_full,static_2p4"
for s in $(seq 21 30); do for k in 1 3 10 30; do
  echo "$OUT/A_k$k/s$s $P --imuQuScale=$k --seed=$s"
  echo "$OUT/B_k$k/s$s $P --boxHalf=750 --finderMode=1 --imuQuScale=$k --seed=$s"
done; done | xargs -P "$(nproc)" -L1 bash -c 'mkdir -p "$0"; '"$BIN"' "$@" --outdir="$0" > "$0/run.log" 2>&1; echo $? > "$0/rc"'
python3 - "$OUT" <<'PY'
import csv, glob, sys, statistics as st
o = sys.argv[1]
for cfg in "AB":
    for k in (1, 3, 10, 30):
        for arm in ("ca_tbl_full", "static_2p4"):
            v = []
            for d in sorted(glob.glob(f"{o}/{cfg}_k{k}/s*")):
                for r in csv.DictReader(open(d + "/arm_summary.csv")):
                    if r["arm"] == arm:
                        v.append((float(r["cep50M"]), float(r["cep95M"])))
            if v:
                print(f"{cfg} k={k:2d} {arm:12s} n={len(v)} CEP50 {st.mean(x[0] for x in v):7.2f}  CEP95 {st.mean(x[1] for x in v):7.2f}")
PY
```

Record the table and how many cells exited 0, out of 160. Do **not** pick a "winner" or change
anything because of it. The registered campaign on the cloud stands as registered. State only
whether k = 10 is within the best of {1, 3, 10, 30} on CEP95 in B without worsening A.
