Search and rescue · GPS-denied terrain

Locating a missing person across three radio tiers

CA-TBL estimates a position where satellite navigation is unavailable. It chooses between long-range LoRa, 2.4 GHz time-of-flight ranging and ultra-wideband according to how uncertain the estimate is, so that precision is spent only where it can be reached.

Radios

Three radios, three roles

Every node carries all three radios. A tier is a choice of radio, not of peer: the same neighbours are reachable on each, at different range and precision.

Tier 1 · coverage

868 MHz LoRa

Reaches furthest, so it covers the whole search area. Position from signal strength and arrival-time differences is coarse; the tier is a floor that keeps every node reachable.

Tier 2 · refinement

2.4 GHz LoRa

Time-of-flight ranging at metre scale, with a precision floor of about 3 m taken from published field measurements. It is used once a node is within a few hundred metres of an anchor.

Tier 3 · precision

Ultra-wideband

Decimetre-level two-way ranging with a floor of 0.10 m, over a range of metres. It confirms a position when a searcher is close, and it is the costliest radio to keep listening.

Method

From measurement to decision

Each cycle follows the same three steps. Only the radio that transmitted is charged for energy, so the cost of escalating is measurable.

1

Measure

Nodes range against gateways and searchers on the active tier. A filter combines the ranges with inertial dead reckoning into a position and an uncertainty.

2

Score

A position-confidence score is computed from that uncertainty. A low score means the estimate is too coarse for the radio in use.

3

Escalate

When enough precise anchors are within reach, the node requests the next radio. When confidence recovers it steps back down, so precision is spent only while it helps.

Console

Build a layout, run it, watch it

  • Place gateways, a base camp, a last known position and a missing node on a map, or load one of three ready scenarios.
  • Run the simulator on that layout. The console reads its output files and replays the run cycle by cycle.
  • Inspect the radio in use over time, every packet a node sent or received, and where each searcher was told to go.

Share of decision cycles with a position within 25 m; the requirement is at least 0.95. These are the paper's evaluated configuration (12 gateways, 12 searchers, 20 paired seeds), not what a console run produces by default.
